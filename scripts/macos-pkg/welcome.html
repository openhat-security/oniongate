OnionGate

This installer places OnionGate in /Applications and registers a privileged helper so Connect and Disconnect do not ask for a password on every use.

You will authenticate once, as administrator, during this install. The install location cannot be changed: the helper only works on the boot volume.

A signed build can also load OnionGate’s connection filter (a Network Extension). After install, approve it in System Settings → General → Login Items & Extensions → Network Extensions if macOS asks. The filter holds and drops outbound flows that are not already Tor. It does not replace the packet lock, and Apple can hide some of its own processes from it. Unsigned builds skip the filter and never appear in that list.
